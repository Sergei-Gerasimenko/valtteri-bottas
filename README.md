# Valtteri Bottas (React rewrite)

React + Vite single-page app that replicates the original static site.

## Scripts

- `npm run dev` – start dev server
- `npm run build` – build for production
- `npm run preview` – serve the production build locally

## Notes

- Global styles imported from `css/app.css`; original structure preserved.
- Static images served from `public/upload`.
- Pages: Home, About, Partners, Media, Contact via React Router.
- Legacy HTML kept under `legacy/` for reference.
